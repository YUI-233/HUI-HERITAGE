# 个人收藏馆（个人书斋）第一阶段蓝图

## 产品定位

个人收藏馆是登录用户自己的“个人书斋”，与账号中心和公共馆藏分开：

- **账号中心**：登录资料、账户状态、用户组、会员图片访问、后台工作入口。
- **个人收藏馆**：个人藏品与个人创作的工作空间。
- **公共馆藏**：HUI HERITAGE 对外展示、检索和研究使用的资料库。

第一阶段首页使用方块式模块，而不把未完成的功能伪装成已可用页面。

## 已确认的信息架构

1. **书籍／文物管理**：个人书籍和个人文物分开管理。录入体验复用现有馆藏的字段、图片和 CSV 导入原则，但数据归属为个人。个人馆藏支持单条创建和 CSV 上传；不进入机构／海外馆藏的 A/B 审核流程。
2. **电子书架**：以现实书架为视觉隐喻，不使用表格或纯列表。一个物理册对应一个书脊；书脊显示书名、作者和自动编号。书架直观反映册数，可继续扩展书架分区、主题和排序。
3. **个人创作中心**：创作文章以方块作品墙展示，不使用列表式展览。有封面图时使用图文方块；无封面图时使用文字方块；点击方块进入文章全文。

## 建议的实现顺序

1. 明确个人藏品和个人文章的隐私／发布规则。
2. 建立独立的数据模型和书籍／文物管理界面。
3. 按实体册生成编号并实现电子书架视图。
4. 建立创作编辑、作品墙和文章详情页。

## 实现前仍需确认

- 个人藏品默认是否只自己可见；公开时是否需要管理员审核。
- 一部多册著作编号是“每套一个”还是“每册一个”。当前建议每册一个，如 `PC-0001`。
- 电子书架是否需要用户自行创建多个书架／分区。
- 个人文章是否有“草稿、仅自己可见、公开”三个状态，以及公开作品是否允许评论。
